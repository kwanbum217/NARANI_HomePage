# 브랜드 기준

> **작성일**: 2026-09-23
> **버전**: v1.0.0
> **정본 위치**: 브랜드 문자열은 `src/data/site.ts`, 로고는 `src/components/Logo.astro`,
> 색은 `src/styles/global.css`

---

## 1. 이름과 관계

| 구분 | 값 | 설명 |
| --- | --- | --- |
| 회사 | `NARANI` | 서비스를 만드는 주체. 회사소개 표면의 이름 |
| 제품 | `BIDBOX` | 공공조달 입찰 분석 서비스. 제품 표면의 이름 |
| 제품 푸터 표기 | `BIDBOX Intelligence` | 제품 하단 고지 |
| 태그라인 | `사용자와 소프트웨어는 나란히 일한다` | 회사 정체성 문장 |

회사명과 제품명을 섞어 쓰지 않습니다. 회사소개 페이지의 주어는 NARANI, BIDBOX 페이지의
주어는 BIDBOX 입니다.

---

## 2. 로고

| 구분 | 구성 | 위치 |
| --- | --- | --- |
| NARANI | 네이비 라운드 사각형 + 나란한 두 기둥 (흰색, 밝은 파랑) | `Logo.astro`, `variant="nani"` |
| BIDBOX | 파랑 라운드 사각형 + 육면체 + 중심점 | `Logo.astro`, `variant="bidbox"` |
| 파비콘 | 위 마크를 SVG 데이터 URI 로 인라인 | `BaseLayout.astro` |

두 기둥은 "나란히" 라는 이름과 태그라인을 형태로 옮긴 것입니다. 로고를 다시 그릴 때도
이 의미를 유지합니다.

로고는 **문자열과 마크를 분리**해 관리합니다. 회사명을 바꾸면 `site.ts` 의 `brand.company`
와 마크 형태를 함께 검토해야 하므로, 로고 변경은
`.agents/skills/brand-refresh/SKILL.md` 절차를 따릅니다.

## 3. 색의 역할

| 역할 | 라이트 | 다크 | 쓰는 곳 |
| --- | --- | --- | --- |
| 바탕 | `#faf9f7` | `#000000` | 페이지 배경 |
| 표면 | `#ffffff` | `#15181c` | 카드 |
| 본문 | `#0a1f33` | `#f2f7fa` | 문단 |
| 보조 | `#5a6b7b` | `#8fa3b3` | 설명, 캡션 |
| 강조 | `#003066` | `#b8ddf0` | 라벨, 링크, 예측 금액 |
| 행동 | `#0073e6` | `#0073e6` | 주요 버튼 |

행동색 `#0073e6` 은 제품 본체와 공유하는 값입니다. 임의로 바꾸면 사이트와 제품이
어긋나므로 변경 전 합의가 필요합니다.

## 4. 보이스

원본 구성안의 문장을 기준으로 삼습니다.

- **담백하게 씁니다.** 수식어로 형용하지 않고 기능과 결과를 그대로 적습니다.
  예: "정보 나열이 아니라, AI로 예상 입찰가까지 제시합니다"
- **사용자를 주체로 둡니다.** "처음 쓰는 사람도 그 자리에서 확인하고 결정하게 합니다"
- **근거를 함께 말합니다.** 금액만 제시하지 않고 근거를 같이 둔다는 원칙이 카피에도
  나타납니다.
- **존댓말을 씁니다.** 반말, 구어체 감탄은 쓰지 않습니다.

## 5. 금지 표현과 표기

| 금지 | 이유 |
| --- | --- |
| 이모지 | 저장소 전체 규칙. `scripts/check-no-emoji.mjs` 가 검사 |
| 느낌표 | 과장으로 읽힘 |
| "최고", "혁신적인", "압도적인" | 근거 없는 형용 |
| 이모 대시(`—`) | 문장을 끊어 의미를 흐림. 쉼표나 마침표로 대체 |
| 영문 대문자 남용 | 제목은 한국어 문장으로 작성 |

표기 규칙:

- 금액은 `₩450,000` 형식으로 천 단위 구분과 원 표기를 함께 씁니다.
- 포인트는 `500포인트` 처럼 숫자와 단위를 붙여 씁니다.
- 날짜는 연도 4자리를 씁니다.

## 6. 연락처

| 항목 | 값 | 상태 |
| --- | --- | --- |
| 이메일 | `surport@narani.my` | 원본 구성안 표기 그대로. 오타 의심 항목으로 등록됨 |
| 채팅 상담 | 평일 09:00-18:00 응답 안내 문구 | 확정 |

이메일은 `src/data/site.ts` 의 `brand.email` 한 곳에서만 정의합니다. 문의 페이지의
`mailto` 링크와 폼 오류 안내 문구가 이 값을 공유합니다. 값이 바뀌면 두 곳이 동시에
바뀝니다.

## 7. 브랜드 변경 절차

브랜드가 바뀔 때 손대는 파일은 정해져 있습니다.

| 바뀌는 것 | 고치는 곳 |
| --- | --- |
| 회사명·제품명·푸터 문구·이메일 | `src/data/site.ts` |
| 로고 마크 | `src/components/Logo.astro` |
| 파비콘 | `src/layouts/BaseLayout.astro` |
| 색 | `src/styles/global.css` `:root` |
| 금액 | `src/data/pricing.ts` |
| 내비 항목 | `src/data/site.ts` 의 `siteNav`, `productNav` |

페이지 파일을 열어야 한다면 그 전에 단일 소스로 올릴 수 있는지 먼저 검토합니다.
절차는 `.agents/skills/brand-refresh/SKILL.md` 를 따릅니다.
