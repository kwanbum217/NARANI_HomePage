## 1. 두 레지스터

이 사이트는 성격이 다른 두 표면을 한 저장소에서 운영합니다.

| 레지스터 | 대상 페이지 | 배경 | 성격 |
| --- | --- | --- | --- |
| `nani` (라이트) | `/`, `/company/` | `#faf9f7` 계열 | 사람·회사·서사. 읽기 편한 에디토리얼 |
| `bidbox` (다크) | `/bidbox/` 이하 5종 | `#000000` 계열 | 데이터·기술·제품. 분석 도구의 인상 |

규칙:

- 한 페이지 안에서 두 레지스터를 섞지 않습니다. 라이트 페이지에 `.reg-dark` 구역을 두지
  않습니다.
- 다크 레지스터는 `BaseLayout` 의 `variant="bidbox"` 로 켜지며, `body` 에 `.reg-dark` 가
  붙습니다. 하위 페이지에서 배경을 다시 칠하지 않습니다.
- 히어로는 방사 그라디언트를 쓰지 않습니다. `.navy-field` 는 `--bb-bg`, `.warm-field` 는
  `--nani-bg` 단색입니다.
- 강조색은 버튼, 현재 내비 밑줄, 요금 강조 막대, 금액 숫자에만 씁니다. 면 전체를 채우지
  않습니다.
- 라이트/다크 어느 쪽이든 **색은 토큰으로만** 지정합니다. 하드코딩한 16진수는 버그입니다.

## 4. 타이포그래피

제목과 본문은 서로 다른 한글 스택을 씁니다. 제목이 라틴 전용 얼굴이 되지 않도록
Myeongjo 계열 뒤에 Pretendard 를 두어, 명조가 없는 환경에서도 한글이 비지 않습니다.

| 역할 | 토큰 | 스택 |
| --- | --- | --- |
| 제목 (`h1`, `h2`, `.display`) | `--font-display` | Apple Myungjo, Nanum Myeongjo, Batang, 그 다음 `--font-body` |
| 본문 (`h3`, UI, 문단) | `--font-body` | Pretendard Variable 계열 |

| 항목 | 값 |
| --- | --- |
| 로딩 | jsDelivr Pretendard 가변 서브셋 (제목·본문 공용) |
| 본문 크기 | `1rem` |
| 본문 행간 | `1.5` |
| 다크 레지스터 본문 행간 | `1.72` (밝은 글자는 광학적으로 얇게 보이므로 보정) |
| 줄바꿈 | `word-break: keep-all` (한국어 어절 보존) |
| 제목 스타일 | 로만만 사용. 이탤릭을 쓰지 않음 |

새 폰트 파일과 패키지는 추가하지 않습니다.

타입 클래스:

| 클래스 | 역할 |
| --- | --- |
| `.display` | 최상위 제목. 700 웨이트, 자간 `-0.02em`, 행간 1.15 |
| `.label` | 작은 라벨. 대문자 변환 없음. 12–13px |
| `.lede` | 도입 문단. 최대 `68ch` |
| `.measure` | 본문 폭 제한 |
| `.num` | 숫자 정렬 (`tabular-nums`) |
| `.strike` | 취소선 금액 |

한국어 사이트이므로 제목에 `text-wrap: balance` 를 쓰지 않고, 문장 중간 `<br />` 로
호흡을 잡습니다. 라틴 대문자 키커를 섹션마다 반복하지 않습니다.

| `.rule` | 구분선 | - |
| `.skip-link` | 본문 건너뛰기 | focus 시 노출 |

내비는 표면마다 모양이 다릅니다.

| 표면 | 데스크톱 내비 | 현재 항목 |
| --- | --- | --- |
| 라이트 | 2행 마스트헤드. 위는 로고, 아래 줄은 링크와 행동 | `--primary` 밑줄 |
| 다크 | 1행. 링크 뒤 세로 선 오른쪽에 행동 | `--bb-accent` 밑줄 |

두 표면 모두 모바일 드로어 DOM 계약은 같습니다.
`header button[aria-controls="mobile-nav"]` 와 `#mobile-nav` 의 `x-show` / `x-cloak` 이며,
`x-transition` 을 붙이지 않습니다. 카드 호버 상승과 진입 모션 클래스는 쓰지 않습니다.

컴포넌트 클래스가 Tailwind 유틸리티와 충돌할 때는 **유틸리티에 important 접미사**를
붙여 우선합니다. 예: `<li class="card p-0!">`.
Tailwind 4 에서 접두사 형태(`!p-0`)는 무효이므로 쓰지 않습니다.

## 6. 포커스와 모션

**포커스**는 모든 대화형 요소에 대해 점선 2px, 오프셋 3px, `--primary` 색으로
표시합니다. 다크 레지스터에서는 `--bb-accent` 로 바뀝니다. `outline: none` 만 쓰는
것을 금지합니다.

**모션**은 다음 원칙만 따릅니다.

1. `transform` 과 `opacity` 만 애니메이션합니다. 레이아웃 속성을 움직이지 않습니다.
2. 진입 애니메이션과 호버 시 카드 상승은 쓰지 않습니다. 페이지가 로드되면 내용이 이미
   제자리에 있습니다.
3. 버튼 눌림의 1px 이동과 포커스 링은 상태 표시로 남깁니다.
4. `prefers-reduced-motion: reduce` 에서는 모든 애니메이션과 전환이 0.01ms 로 줄고
   부드러운 스크롤이 해제됩니다.
5. 상태 변화를 설명하지 못하는 전환은 넣지 않습니다.
