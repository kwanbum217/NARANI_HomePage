### 2.4 폼 필드 접근성 (커밋 `5fe6421`, `f11715c`, `7128f08`, `7c878e5`)

게이트 8단계가 전부 통과한 상태에서 찾은 결함입니다. 게이트는 Alpine 검증 결과만

| 항목 | 내용 |
| --- | --- |
| 필수 표시 | 문의·데모 폼의 텍스트 입력 7개 필드에 `aria-required="true"`. `required` 는 넣지 않았습니다 — 폼에 `novalidate` 가 있고 검증이 Alpine 이라서 브라우저 네이티브 툴팁이 이중으로뜹니다 |
| 길이 제한 | 성함 100, 이메일 254(RFC 5321 최대 경로 길이), 문의내용 2000. `src/data/enquiry.ts` 단일 소스에 두고 페이지가 거기서 읽습니다. 나머지 두 값은 무한 입력 방지용 상한이며 근거 문서가 없습니다 |

**음성 검증**: `aria-required` 를 지우면 종료 코드 1 과

로 멈춥니다. 되돌리면 종료 코드 0. 코디네이터가 직접 수행했습니다.

### 2.6 오보고 철회 (커밋 없음)

이번 회차에 제가 보고했다가 철회한 결함 세 건입니다. 다음 세션이 같은 실수를
반복하지 않도록 기록합니다.

| 잘못 보고한 것 | 사실 | 제가 왜 틀렸는가 |
| --- | --- | --- |
| 폼 `aria-describedby` 누락 | 이미 정상. 오류 발생 시 `c-name-error` 로 연결되고 `aria-invalid` 가 `true` | 초기 렌더 상태만 봤습니다. Alpine 이 빈 값을 `null` 로 바인딩하므로 초기엔 속성이 없는 게 정상입니다 |
| 서비스 페이지 아이콘 깨짐 | 정상. `svg` 엘리먼트·SVG 네임스페이스·`getBBox` 모두 실제 값 반환 | `querySelectorAll('.cap-mark svg')` 라는 잘못된 셀렉터로 "SVG 0개"라 읽고, 축소된 스크린샷을 오해했습니다 |
| 요금 다이얼로그 포커스 트랩 | 정상. 실제 Safari 창에서 Tab 을 8회 넘게 눌러도 안으로 순환합니다 | 헤드리스 Chrome CDP 합성 키 이벤트가 `inert` 처리를 우회해 포커스를 `BODY` 로 떨어뜨립니다. 실제 사용자 키 입력에서는 일어나지 않습니다 |

**세 건의 공통 원인은 "도구가 보여준 것을 그대로 제품 사실로 믿었다"입니다.**
1건은 초기 상태를, 2건은 잘못된 셀렉터를, 3건은 합성 이벤트를 그대로 신뢰했습니다.
3건은 이 저장소에서 확인 가능한 경로가 셋뿐이었습니다 — 헤드리스 Chrome CDP
(가짜 양성), WebKit `evaluateJavaScript`(키 이벤트 불가), 실제 Safari 창에서
사람이 누르는 것(유일하게 재현 가능). 도구가 재현한다고 확인하는 것과
사용자에게 재현되는 것은 다릅니다. 결함으로 기록하기 전에 그 도구가 실제 사용자
경로를 재현하는지 먼저 따져 보십시오.

3건에 대해 저는 포커스 트랩 자바스크립트를 네 가지 방식(keydown preventDefault,
focusout, tabindex=-1, document focusin 가드)으로 시도했습니다. 전부 되돌렸고
main 은 `dc218b8` 로 이 문서를 쓸 때와 같습니다. **결함이 없었으므로 수정한
코드가 없습니다.**

| `auto-approved (matched rule)` 화면을 자동 통과로 읽음 | 그 줄은 **이전 명령**에 대한 것입니다. 현재 대기 중인 명령의 증거가 아닙니다. 화면에 `Permission required` 가 뜨면 멈춘 것입니다 |
| W2 가 자기 worktree 에서 W1 의 파일을 기다림 | worktree 는 git 으로 분리되어 파일을 공유하지 않습니다. 워커에게 "기다려라"고 지시하면 영원히 기다립니다. 값을 직접 전달하십시오 |
