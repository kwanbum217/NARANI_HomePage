## 3. 접근성 게이트 결함

검토 문서는 읽기 전용이라 실행 검증을 하지 않았습니다. 이어받은 세션이 `dist/`
복사본의 한 페이지를 `lang="en"` 으로, 요금 페이지 제목을 다른 값으로 바꿔 음성
테스트를 했습니다.

| 게이트 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 인터랙션 | 종료 코드 1, 실패 사유 출력 | 변경 없음 |
| 접근성 | 종료 코드 1, 실패 사유 **출력 없음** | 종료 코드 1, `LANG: en` 과 이슈 건수 출력 |

원인은 `set -e` 아래에서 `A11Y_OUT="$(...)"` 대입이 1 을 받자마자 스크립트가 끝나
다음 줄의 출력이 실행되지 않은 것입니다. 종료 상태를 따로 받도록 고쳤습니다.
음성 테스트용 복사본과 임시 서버는 저장소 밖에서 만들고 정리했습니다.
