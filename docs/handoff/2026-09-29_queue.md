코드 변경이 아닙니다. [`../ops/BUILD_AND_DEPLOY.md`](../ops/BUILD_AND_DEPLOY.md) 5장의
배포 전 체크리스트에 있습니다.

- 브라우저 3종 육안 확인. 검증 도구는 WebKit 하나이고, 이번 아이콘도 WebKit 만 봤습니다.
- 실제 기기에서 모바일 확인.
- 문의 폼의 클립보드 거절 분기는 이 환경에서 재현하지 못했습니다. `127.0.0.1` 과 `localhost` 가 보안 컨텍스트라 거절을 만들 수 없습니다. 정본 서술은 [`../context/CURRENT_STATE.md`](../context/CURRENT_STATE.md) 5장 10번입니다.
