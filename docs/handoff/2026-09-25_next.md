## 3. 다음 과업

3종 브라우저 렌더 비교를 수행합니다. 목적은 WebKit만 도는 `npm run verify`의
사각을 보완하는 것입니다. 근거는
[`../analysis/README.md`](../analysis/README.md)의 예정된 분석 주제입니다.
번들 크기 기준선은 이미 [`../analysis/번들_20260925.md`](../analysis/번들_20260925.md)에
있습니다. 그 문서를 다시 쓰지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 빌드된 8페이지. 홈, 회사, BIDBOX 4페이지, 404 |
| 브라우저 | 이 맥에 설치된 Chrome과 Firefox. 없으면 그 브라우저를 설치하지 말고, 없음으로 기록하고 멈춥니다 |
| 볼 것 | 콘솔 오류, 320px에서 가로 넘침, 본문 배경색 |
| 비교 기준 | WebKit 결과는 [`../context/CURRENT_STATE.md`](../context/CURRENT_STATE.md)를 링크로만 가리킵니다. 대비 숫자를 이 문서나 분석 문서에 복사하지 않습니다 |
| 산출 | `docs/analysis/` 아래 날짜가 있는 분석 문서 하나. 측정 조건과 실제로 본 값만 적습니다 |
| 브랜치 | `main`에서 `feat/브라우저-비교`로 시작합니다 |

하지 않을 일:

- 호스트, 도메인, `astro.config.mjs`의 `site`, 이메일 표기, 문의 수신 주소를 바꾸지 않습니다.
- 테마 레지스터와 결제 주소를 바꾸지 않습니다. 결제는 제품 저장소에 공개 라우트가 없습니다.
- 패키지를 추가하지 않습니다. 측정값을 지어내지 않습니다.
- 워커를 쓰면 구현이 끝난 뒤에만 검토하고, 끝난 세션은 닫습니다.
