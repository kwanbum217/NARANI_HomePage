# W2 FAQ 데이터 모듈 및 섹션

## 변경 내용

`src/data/faq.ts`에 질문과 답변 타입을 정의하고, 기존 요금·서비스·데모 페이지 카피에 근거한 FAQ 항목을 모았습니다. 요금 페이지와 서비스 페이지는 이 데이터를 공통으로 가져와 의미 구조가 있는 `section`, `h2`, `dl`, `dt`, `dd`로 표시합니다.

## 근거 범위

FAQ 답변은 `src/data/pricing.ts`의 포인트 사용 안내, `src/pages/bidbox/service.astro`의 용역 분야와 예측 근거 안내, `src/pages/bidbox/demo.astro`의 데모 신청 안내를 바탕으로 작성했습니다. 예측 성과 수치나 접수 완료를 주장하는 문구는 추가하지 않았습니다.

## 검증

`npm run verify`를 실행했습니다. 타입 체크, 정적 빌드, 링크·사이트맵 검사, WebKit 렌더, 폰트 서브셋, 반응형·접근성, 인터랙션 단계까지 통과했습니다. 빌드 결과에서 두 페이지 모두 공통 FAQ 제목과 항목을 출력하는 것을 확인했습니다.

새 카피의 글리프를 포함하도록 `python3 scripts/build-font-subset.py`로 서브셋을 재생성했습니다.
