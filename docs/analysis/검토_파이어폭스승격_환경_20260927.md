## 검증한 것과 검증하지 못한 것

검증한 것은 다음입니다. 원시 JSON 네 건을 열어 정본 Firefox 절의 대비치수 8행, 인터랙션 3행, 320px 8행과 `measuredAt` 과 `run` 제외 일치를 확인했습니다. 두 `BUILD_HEAD.txt` 의 커밋이 정본과 분석 문서의 커밋과 같은지 확인했습니다. 기준 커밋 `3d67782` 과 작업 트리를 대조해 삭제 줄이 Node 와 npm 두 줄뿐임을 확인했습니다. `node -v`, `npm -v`, `swift --version`, `which node` 를 직접 실행해 환경 문서와 원시 txt 와 일치함을 확인했습니다. `package.json` 과 `package-lock.json`, 설치본 다섯 패키지, `ci.yml` 23행의 값을 읽어 환경 문서 결과표와 일치함을 확인했습니다. 세 변경 파일에 이모지가 없고 인용 블록과 구분선이 있음을 확인했습니다.

검증하지 못한 것은 다음입니다. 제약에 따라 `npm run verify`, `astro build`, `scripts/verify.sh`, 패키지 설치를 실행하지 않아 빌드와 렌더, 링크 무결성, 반응형과 접근성 실측은 확인하지 못했습니다. `dist/` 재생성과 Firefox 재측정도 수행하지 않아 원시값 자체의 재현은 분석 문서의 두 실행 일치 기록에 의존했습니다.
