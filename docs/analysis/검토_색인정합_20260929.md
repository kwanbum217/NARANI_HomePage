## 4. 검증한 것과 검증하지 못한 것

### 4.1 검증한 것

- 두 워크트리의 `git diff` 전문을 직접 읽었습니다. `git status --short` 로 변경 파일 목록도 확인했습니다.
- 추가된 링크 20개를 전부 파일 존재로 확인했습니다. `docs/README.md` 의 6개 절과 `docs/analysis/README.md` 전체의 링크를 절 경로 기준으로 풀어 결손 0건입니다.
- 5절 건수를 세 가지 방법으로 대조했습니다. `docs/analysis/` 의 실제 `.md` 개수, 5절 표 행 수, 머리말 숫자입니다.
- `docs/README.md` 를 절 단위로 잘라 HEAD 판본과 SHA-256 해시를 비교해 W1 은 2절만, W2 는 5절만 바뀌었음을 확인했습니다. 변경 줄이 속한 절을 diff 행 번호로도 확인했습니다.
- W1 이 쓴 1열 10개와 W2 가 쓴 주제 10개에 대해 각 문서의 머리말과 목차를 열람했습니다. W2 의 "리뷰어 권고 반영 주장 대조" 는 `검토_권고_20260926.md` 7장 제목 "리뷰어 권고 7건 반영 주장의 대조 가능성" 에서 온 것임을 확인했습니다. 파일명이 아니라 본문 근거로 볼 수 있는 근거입니다.
- 새 행의 설명 열에 실측 수치와 판정 문구가 없는 것을 행 단위로 확인했습니다.
