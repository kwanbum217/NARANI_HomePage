## 질문

Chrome 헤드리스에서 `scripts/audit/render.swift` 의 `probe` 와 같은 선택자로 재단 실측을
했을 때, WebKit 으로 잰 기준 표([`../context/CURRENT_STATE.md`](../context/CURRENT_STATE.md)
3장 컴포넌트 실측)와 같은 값이 나오는가. 측정 항목은 다음 4개다.

| 항목 | 선택자 |
| --- | --- |
| 데스크톱 내비 CTA 높이 | `header nav a.btn-primary` 의 `getBoundingClientRect().height` 반올림 |
| 허브 카드 padding-top | `main a.card` 의 `getComputedStyle().paddingTop`, 없으면 `null` |
| 요금 행 개수 | `#plans li.card` 개수 |
| 요금 다이얼로그 존재 | `dialog` 요소 존재 여부 |

---

## 방법

1. 이미 빌드된 복사본 `/tmp/narani-chrome-cta-20260927/dist` 를 문서 루트로
   `python3 -m http.server 8912` 로 서빙했다.
2. `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new
   --remote-debugging-port=9912` 로 Chrome 을 띄웠다. 브라우저 버전은 `/json/version` 으로
   154.0.8037.58 임을 확인했다.
3. 측정은 Node 내장 `fetch` 와 `WebSocket` 만 쓴 별도 스크립트로 했다. 패키지는 설치하지
   않았고 스크립트는 저장소에 넣지 않았다.
4. 페이지마다 `Emulation.setDeviceMetricsOverride` 로 뷰포트를 맞춘 뒤 이동하고, `load`
   이벤트 뒤 1500ms 를 기다린 다음 `Runtime.evaluate` 로 위 4개 항목을 읽었다.
5. 같은 스크립트를 두 번 실행해 원시 JSON 을 `/tmp/narani-chrome-cta-20260927/run1.json` 과
   `/tmp/narani-chrome-cta-20260927/run2.json` 에 각각 남겼다. 두 번째 실행이 첫 번째
   파일을 덮어쓰지 않았다.
6. 측정 후 Chrome 과 `http.server` 프로세스를 종료했다.

페이지와 뷰포트는 `scripts/verify.sh` 의 `PAGES` 와 같다.

확인했다(요금 행은 `.card` 가 아닌 그리드 클래스를 쓴다). 원시 JSON 은
`/tmp/narani-chrome-cta-20260927/run1.json` 과 `/tmp/narani-chrome-cta-20260927/run2.json`
에 남아 있고 이 표의 숫자와 같다.

## 해석

- Chrome 으로 잰 4개 항목은
  [`../context/CURRENT_STATE.md`](../context/CURRENT_STATE.md) 3장 컴포넌트 실측 표와
  **전 항목 일치**한다. CTA 높이, 허브 카드 padding-top, 요금 행 개수, 다이얼로그 존재
  여부 모두 같다.
- 두 번의 실행이 서로 같았으므로 이 측정은 페이지 로드 타이밍 변동에 흔들리지 않는
  안정적인 값으로 본다.
- CTA 높이 44px 는 Tailwind 4 important 접미사(`min-h-[44px]!`)가 헤드리스 Chrome 에서도
  적용됨을 뜻한다.

## 한계

- 이 측정은 `--headless=new` 모드의 값이다. 일반 창(헤드리스가 아닌) Chrome 에서 같은
  값이 나온다고 단정할 수 없다.
- 뷰포트는 `Emulation.setDeviceMetricsOverride` 로 고정한 값이므로 실제 창 크기 조절과
  스크롤바 상황이 다를 수 있다.
- 측정은 빌드 복사본 한 벌 위에서 이뤄졌으므로, 소스를 고쳐 다시 빌드하면 값이 달라질 수
  있다. 이 문서는 코드 변경 없이 측정만 기록했다.
- 본 문서는 4개 치수 항목만 다룬다. 대비값이나 인터랙션 동작은 다른 기록을 참고한다.
