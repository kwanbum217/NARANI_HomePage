## 질문

배포 전 시점에서 현재 정적 사이트의 번들 크기 기준선은 얼마이며, 회귀 감지를 위해 어떤 파일을 주시해야 하는가?

---

## 방법

1. `dist/` 를 재빌드하지 않고 디스크에 있는 산출물을 그대로 측정했습니다.
2. 총량은 `find dist -type f -exec stat -f "%z" {} \;` 의 합으로, 디스크 점유는 `du -sk dist` 로 측정했습니다.
3. 파일별 바이트는 `find dist -type f -exec stat -f "%z %N" {} \; | sort -rn` 로 정렬했습니다.
4. 압축 크기는 각 파일에 `gzip -c` 를 적용해 바이트를 셌습니다.

측정에 사용한 `dist/` 는 이 작업에서 생성한 것이 아니라, JSON-LD 와 파비콘 변경을 반영한 이전 `npm run verify` 가 남긴 산출물입니다. 이 작업은 재빌드나 `npm`, `astro`, `scripts/verify.sh` 실행 없이 기존 산출물만 읽었습니다.
