## 변경 내용

- `src/data/site.ts`의 BIDBOX 프로그램 CTA 문구를 `요금 보기`로 바꾸고, 링크는 `/bidbox/pricing/`로 유지했습니다.
- `src/pages/bidbox/index.astro`의 주요 CTA가 `primaryCta.program`의 라벨과 링크를 사용하도록 연결했습니다.
- `src/layouts/BaseLayout.astro`에서 BIDBOX 페이지에만 `SoftwareApplication` JSON-LD 노드를 추가했습니다. 이름은 `brand.product`, 설명은 해당 페이지 설명, URL은 Astro 사이트 기준 `/bidbox/`이며 요금 정보는 넣지 않았습니다. Organization과 WebSite 노드는 기존대로 유지했습니다.

---

## 검증 결과

`npm run verify`를 실행해 전체 8단계가 통과했습니다. 빌드 후 `/bidbox/`의 JSON-LD에 `SoftwareApplication` 노드가 있고, `/company/`는 Organization과 WebSite만 포함하는 것을 확인했습니다. 빌드된 BIDBOX 페이지에서 `요금 보기` 문구도 확인했습니다.
