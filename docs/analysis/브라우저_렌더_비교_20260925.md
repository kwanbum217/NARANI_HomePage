# 3종 브라우저 렌더 비교

> **작성일**: 2026-09-25
> **상태**: 완료 (Firefox 는 미설치로 측정하지 않음)
> **측정 조건**: 대상은 커밋 `df7e517` 을 `npm run build` 한 `dist/` 의 복사본 8페이지입니다.
> Chrome 은 `python3 -m http.server` 로 서빙하고 Google Chrome 153.0.8010.53 을 `--headless=new`
> 로 띄워 CDP(Node 내장 WebSocket)로 측정했습니다. WebKit 은 같은 날 `npm run verify` 를
> 다시 실행한 결과입니다(macOS 26.6.2, WebKit 21624.5.1.11.3). 표본은 페이지당 1회 측정이고,
> 같은 조건으로 한 번 더 실행해 값이 같은지 확인했습니다.

---

## 질문

`npm run verify` 는 WebKit 에서만 돕니다. Chrome 과 Firefox 에서도 콘솔 오류, 320px 가로 넘침,
본문 배경색이 WebKit 과 같게 나오는가?

---

## 방법

| 브라우저 | 뷰포트 | 수집 항목 |
| --- | --- | --- |
| Chrome | 1440 폭. 높이는 `/`, `/bidbox/pricing/`, `/bidbox/demo/`, `/bidbox/contact/`, `/404.html` 이 1700, 나머지가 1900 (`scripts/verify.sh` 의 `PAGES` 와 같음) | `Runtime.exceptionThrown`, `Runtime.consoleAPICalled`(error, warning), `Log.entryAdded`(error, warning), `body` 의 배경색·글자색, `documentElement.scrollWidth` |
| Chrome | 320x900, deviceScaleFactor 2, mobile | 위 콘솔 항목, `documentElement.scrollWidth`, `body.scrollWidth`, `clientWidth`, `body` 배경색, 오른쪽 끝이 `clientWidth` 를 1px 넘게 벗어난 요소 |
| WebKit | `scripts/verify.sh` 의 기본값 | `npm run verify` 전체 |
| Firefox | 해당 없음 | 설치 여부만 확인 |

Chrome 측정은 페이지마다 load 이벤트 뒤 1500ms 를 기다렸습니다. 측정 스크립트는 Node 내장
WebSocket 과 fetch 만 쓰는 일회용 파일이며, 추적하지 않는 작업 폴더에 두었다가 측정 뒤 저장소 밖으로 옮겼습니다.
같은 측정을 다시 하려면 위 조건으로 스크립트를 새로 작성해야 합니다.

`dist/` 복사본은 `feat/브라우저-비교` 브랜치를 만든 직후 `npm run build` 로 만들었습니다. 같은
명령에서 `git rev-parse --short HEAD` 가 `df7e517` 을 출력했습니다.

Firefox 설치 여부는 설치 없이 다섯 가지로 확인했습니다. `ls /Applications`,
`ls ~/Applications`, `mdfind "kMDItemCFBundleIdentifier == 'org.mozilla.firefox'"`,
`which firefox`, `ls -d ~/Library/Caches/ms-playwright/firefox-*` 입니다.

### WebKit

같은 날 다시 실행한 `npm run verify` 는 종료 코드 0 이었습니다. 로그에는 페이지 8개, 참조 69건,

기준값은 [`../context/CURRENT_STATE.md`](../context/CURRENT_STATE.md) 3장에 있습니다.

### Firefox

다섯 가지 확인 모두에서 Firefox 가 나오지 않았습니다. `which firefox` 는 `firefox not found`,
`mdfind` 는 출력 없음, Playwright 캐시에는 `firefox-*` 가 없었습니다. 인계 지시에 따라 설치하지
않았고 측정하지 않았습니다.

## 해석

- Chrome 에서 두 폭 모두 8페이지 콘솔 오류와 경고가 0건이었습니다.
- Chrome 의 body 배경색 문자열은 라이트 3페이지와 다크 5페이지로 나뉩니다. 이 값은
  [`../context/CURRENT_STATE.md`](../context/CURRENT_STATE.md) 3장 표의 라이트·다크 배경 값과
  문자열이 같습니다. 두 레지스터 배분이 Chrome 에서도 같다는 뜻입니다.
- Chrome 320 폭에서는 doc scrollWidth 가 clientWidth 를 넘은 페이지가 없었고, 오른쪽으로 벗어난
  요소도 없었습니다.
- 1440 폭 `/bidbox/service/` 의 scrollWidth 1425 는 innerWidth 보다 작은 값입니다. 페이지가
  넘친 것은 아닙니다. 세로 스크롤바 폭만큼 줄었을 가능성이 있지만 확인하지 않았습니다.
