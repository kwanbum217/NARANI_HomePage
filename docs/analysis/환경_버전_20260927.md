## 방법

1. 저장소 루트에서 `node -v` 와 `which node` 로 Node 실행 파일의 버전과 경로를 읽었습니다.
2. `npm -v` 로 npm 버전만 조회했습니다. `npm install`, `npm ci`, `npm run`, `npx` 는 실행하지 않았습니다.
3. Node 내장 `fs` 로 다음을 읽었습니다.
   - `package.json` 의 `dependencies` 선언 범위(esbuild 는 선언이 없어 `(선언 없음)` 으로 기록)
   - `node_modules/<패키지>/package.json` 의 `version`
   - `package-lock.json` 의 `packages["node_modules/<패키지>"].version`
   - `package.json` 의 `engines`
   대상 패키지는 `astro`, `tailwindcss`, `@tailwindcss/vite`, `alpinejs`, `esbuild` 다섯입니다.
4. `grep -n "node-version" .github/workflows/ci.yml` 로 CI 의 Node 버전을 읽었습니다.
5. `swift --version` 의 첫 줄로 Swift 버전을 읽었습니다.
6. 위 1~5를 한 번의 실행으로 묶어 `/tmp/narani-env-20260927/run1.txt` 에 저장했고, 같은 실행을 반복해 `/tmp/narani-env-20260927/run2.txt` 에 저장했습니다. 두 파일은 측정 시각 줄만 다르고 나머지는 같습니다.
7. 두 파일을 `diff` 로 대조했습니다. 전체 diff 는 측정 시각(`measuredAt`) 한 줄만 다르고(`2c2`), 그 줄을 제외한 나머지는 완전히 같았습니다. 측정 시각 줄이 다르므로 `diff` 종료 코드는 1 입니다.
8. 측정은 저장소 파일을 수정하지 않는 읽기 전용 명령으로만 수행했고, 측정 스크립트와 원시 파일은 저장소 밖에 두었습니다.
