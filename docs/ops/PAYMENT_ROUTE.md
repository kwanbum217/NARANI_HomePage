## 3. 상세 소견

API 라우터 아홉 가지 가운데 요금 결제나 포인트 충전을 담당하는 경로는 없습니다. 회원과 자동화, 공고, 챗봇, 평가, 예측, 상태 확인만 있습니다. 프론트엔드는 결제 화면이 없는 단일 페이지 앱입니다.

제품 문서도 같은 방향을 가리킵니다. 감사 검증 표는 결제 부재를 사실로 적고 있으며, 사용자 결정 기록은 결제를 보류하고 내부 베타를 유지한다고 적고 있습니다. 연결할 정확한 경로나 주소가 존재하지 않으므로 임의의 URL을 만들지 않았습니다.
